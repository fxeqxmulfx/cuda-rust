# Shared Sphinx deps for cuda-oxide-book and cutile-rs/cutile-book.
# Keep in sync with cuda-oxide-book/requirements.txt — the Pages workflow
# installs from that file once for both books.
#
# Upper-bounded on the major: the cuda-oxide build runs warnings-as-errors (-W),
# and a new major routinely introduces warnings, which would redden every PR
# and the main-branch deploy overnight. Bump a bound deliberately instead.
#
# Every requirement carries one, not just Sphinx. The rationale is not
# Sphinx-specific: myst-parser decides what counts as a malformed directive or
# an unresolved cross-reference, and the theme emits its own warnings, so
# either can fail `-W` on a release nobody asked for.
#
# Minimum versions are the current stable releases; upper bounds keep
# future major upgrades explicit.
sphinx>=9.1.0,<10
pydata-sphinx-theme>=0.23.0,<1
myst-parser>=5.1.0,<6
sphinx-copybutton>=0.5.2,<1
sphinx-design>=0.7.0,<1
sphinx-sitemap>=2.9.0,<3
# Local live-reload only; no CI path invokes it.
